\[\sum_{i=1}^{12}f_X(x)=1\]

Code 
f <- rep(1/12,12)
sum(f)

\(\frac{1}{12}+\frac{1}{12}+\frac{1}{12}.....+\frac{1}{12}=1\)

  1. Compute the expected value of \(X\).

\[{E}[X]=\sum_{i=1}^{12}~x_i\*f_X(x)\]

Code

f <- rep(1/12,12)

expected_value <- sum(x * f)
expected_value
[1] 6.5

\({E}[X]=1*\frac{1}{12} + 2*\frac{1}{12}+3*\frac{1}{12}.....12*\frac{1}{12}=6.5\)

  1. Compute the variance of \(X\).

\[{Var}[X]=\sum_{i=1}^{12} (x_i-{E}[X])^2*f_i\]

Code

    3. Plot the Student t distribution with 15 degrees of freedom using curve() and dt(). Specify the range as [-5,5] using xlim. Choose a different colour, i.e. col=3. To learn more about dt, type ?dt in your console.
    4. Plot the Student t distribution with 25 degrees of freedom using curve() and dt(). Specify the range as [-5,5] using xlim. Choose a different colour, i.e. col=4. To learn more about dt, type ?dt in your console.
    5. Include the following legend in you plot:
      legend("topright",  c("N(0, 1)", "M=2", "M=4", "M=25"),  col = 1:4,  lty = c(1, 1, 1, 1))
Code 
# (a) Plot the standard normal and Student t distributions

# (i) Standard Normal Distribution

xlab = c(-5,5), ylab = "Density",
main = "Densities of t Distribution",
col = "1")

# (ii) Student T distribution, df=5

            from = 5, to = -5,
            xlab = c(-5,5), ylab = "Density",

# (iii) Student T distribution df=15

            xlab = c(-5,5), ylab = "Density",
